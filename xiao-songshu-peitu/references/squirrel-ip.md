# 小松鼠 IP

## 角色定义

小松鼠是中文内容配图里的固定视觉 IP。它不是普通森林松鼠，也不是儿童卡通角色，而是一个认真整理信息、搬运经验、缓存知识的小助手。

默认每张图都要出现小松鼠。小松鼠必须参与画面的核心动作，不能只是站在角落里卖萌。

## 外形

- 橙棕色毛绒小松鼠。
- 奶油色脸颊和口鼻区域。
- 大而圆的棕色眼睛。
- 圆耳朵。
- 小鼻子。
- 两颗门牙。
- 两只短爪子。
- 深绿色卷曲大尾巴。
- 尾巴上有蓝色发光线路和圆形节点。
- 整体像干净现代的 3D App 吉祥物，但不要变成普通图标。

## 性格

- 聪明、好奇、认真。
- 像一个知识管理员或信息收纳员。
- 有点忙乱，但不蠢。
- 有亲和力，但不卖萌。
- 适合承担“收集、筛选、缓存、沉淀、搬运、归档”这些动作。
- 在正文解释图里要像正在工作的知识整理员，不是镜头前的主角。

## 常见职责

让小松鼠承担核心动作：

- 把纸条搬进树洞。
- 把混乱资料分进抽屉。
- 把经验坚果放进缓存篮。
- 推小车搬运任务。
- 操作小型分拣机器。
- 给候选内容贴标签。
- 守着知识仓库的入口。
- 从一堆信息里挑出有用内容。
- 把临时内容放进观察篮。
- 把成熟经验放进长期柜。
- 从知识库抽屉里取出旧经验递给新任务。
- 用尾巴上的蓝色线路连接多个信息来源。
- 拿印章挡住未经确认的内容。

## 禁止

- 不要让小松鼠只是装饰。
- 不要变成普通松鼠。
- 不要变成儿童绘本角色。
- 不要变成真实动物照片。
- 不要丢掉深绿色尾巴。
- 不要丢掉蓝色发光线路。
- 不要给它复杂服装。
- 不要让表情过度夸张。
- 不要让角色抢走结构表达。
- 正文解释图里不要大头居中。
- 不要复刻参考图的白色 App 图标边框构图。

## 判断标准

如果去掉小松鼠，图的核心隐喻还能完全成立，说明小松鼠太装饰了；要重写提示词，让小松鼠成为动作主体。

如果去掉深绿色卷曲尾巴和蓝色发光线路，角色仍然能被认成普通松鼠，说明固定 IP 特征不够强；要重生成或编辑。

如果小松鼠占画面太大，读者第一眼只看到角色而看不懂结构，说明它更像封面主视觉，不适合作为正文解释图；要缩小角色，让信息结构成为主角。
