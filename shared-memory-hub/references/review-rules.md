# 候选确认规则

`03-候选确认清单` 里的内容，需要先审阅，再决定是否进入稳定知识库。

## 审阅分类

每条候选内容只归入一类：

1. 升级到 `02-可复用经验库`
2. 继续保留在 `03-候选确认清单`
3. 归档到 `90-归档废弃`
4. 作为 `01-核心规则` 候选提交用户确认

## 升级到可复用经验的标准

只有满足以下条件时，才建议升级：

- 解决的是会反复遇到的问题
- 有明确适用场景
- 有稳定步骤或判断标准
- 已经验证，或者有明确依据支撑
- 不是临时想法
- 不包含敏感信息

## 核心规则候选标准

只有满足以下条件时，才建议作为核心规则候选：

- 会影响多个智能体或长期工作方式
- 在多个场景下稳定适用
- 可以压缩成清晰规则
- 写入前必须得到用户明确确认

## 归档标准

以下情况建议归档：

- 重复
- 过期
- 已经被正式经验吸收
- 太模糊
- 判断错误或已被替代
- 只对某次旧对话有价值
- 包含敏感信息，不适合保留在知识库

## 输出方式

候选审阅先输出确认清单。

用户确认前，不移动、不改写、不删除任何文件。
