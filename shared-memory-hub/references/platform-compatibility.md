# 平台兼容说明

这个 Skill 的核心是“共享记忆库工作流”，不是某个平台专属功能。

只要某个平台能读取和写入本地 Markdown 文件，就可以按这套结构接入。

## Codex

推荐安装位置：

```text
~/.codex/skills/shared-memory-hub
```

适合能力：

- 创建本地共享记忆库
- 读取核心规则和可复用经验
- 写入聊天摘要和候选确认
- 创建每日整理、每周审阅等自动化任务

注意：

- 自动化任务不会因为安装 Skill 自动创建。
- 需要用户明确要求创建自动化任务。
- 修改 `01-核心规则` 和 `02-可复用经验库` 前必须等用户确认。
- Codex 的本地规则只保留共享记忆库短入口；如果本地规则补充了新判断，必须同步更新本 Skill。

## Hermes

推荐安装位置：

```text
~/.hermes/skills/shared-memory-hub
```

适合能力：

- 从飞书、微信或其他 Gateway 会话中整理有价值内容
- 写入 `04-聊天摘要`
- 写入 `03-候选确认清单`
- 使用 cron job 做每日整理

注意：

- Hermes 的 cron job 需要单独创建。
- 不同 Hermes 环境的工具权限不同，创建任务前要确认能读写目标文件夹。
- 如果使用 Obsidian iCloud 路径，可能需要 macOS 完全磁盘访问权限。
- Hermes 本地 Skill、cron 提示词和运行时快照可能不同步；修改本 Skill 后，要同步运行副本并刷新 Hermes 的 Skill 快照或重载运行环境。

## Claude Code

Claude Code 不一定使用 Codex 或 Hermes 这种 Skill 目录机制。

推荐接入方式：

- 如果 Claude Code 支持 Skill 或可引用本 Skill，优先使用本 Skill。
- 如果暂时不支持，把共享记忆库入口规则写入用户或项目级常驻规则。
- 在项目的规则文件中说明共享记忆库路径。
- 要求它只检索共享记忆库，不检索整个 Obsidian。

适合能力：

- 在开发项目中按需读取长期经验
- 写入项目相关聊天摘要或候选确认
- 复用项目背景、排查经验和协作规则

注意：

- 不要假设 Claude Code 能自动创建后台定时任务。
- 如果需要定时整理，应使用系统计划任务或外部自动化工具。

## OpenClaw

OpenClaw 是否支持 Skill 目录，取决于具体部署方式。

推荐接入方式：

- 如果 OpenClaw 支持本地 Skill 或规则目录，把本 Skill 作为规则包接入。
- 如果不支持，复制 `SKILL.md` 中的核心规则到 OpenClaw 的常驻规则或项目规则。
- 确认 OpenClaw 是否能访问共享记忆库所在路径。

适合能力：

- 读取核心规则和可复用经验
- 写入候选确认或任务摘要
- 在长期任务中复用同一套记忆库

注意：

- 不要默认让 OpenClaw 自动改核心规则。
- 不要默认给 OpenClaw 过宽的本机或内网访问权限。
- 如果部署在 Docker、NAS 或远程环境，需要先确认路径映射和读写权限。

## 通用接入标准

无论哪个平台，都遵守：

1. 简单任务不用查库。
2. 复杂任务、长期项目、历史规则、本机环境、自动化相关任务要查库。
3. 只查共享记忆库，不查整个 Obsidian。
4. 优先查 `01-核心规则` 和 `02-可复用经验库`。
5. 自动写入只允许进入 `04-聊天摘要` 和 `03-候选确认清单`。
6. 不自动修改 `01-核心规则` 和 `02-可复用经验库`。
7. 创建自动化任务前必须说明读写范围、运行时间和风险，等待用户确认。
8. 优先通过本 Skill 保持跨平台规则一致；本地规则出现新补丁时，要反向同步到本 Skill。
