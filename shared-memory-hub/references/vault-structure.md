# 共享记忆库目录结构

共享记忆库是一个用于沉淀长期智能体经验的 Obsidian 或本地 Markdown 文件夹。

默认文件夹名：

```text
AI智能体记忆库
```

标准结构：

```text
AI智能体记忆库/
├── 00-共享记忆库入口.md
├── 01-核心规则/
├── 02-可复用经验库/
├── 03-候选确认清单/
├── 04-聊天摘要/
├── 05-项目资料/
└── 90-归档废弃/
```

## 各目录用途

`00-共享记忆库入口.md`
总入口。说明这个库是什么、怎么用、智能体应该遵守什么边界。

`01-核心规则`
少量长期稳定规则。会影响多个智能体或长期工作方式。不能自动修改。

`02-可复用经验库`
已经确认、以后可以复用的方法、流程和判断标准。智能体应该优先查询，但不能自动升级写入。

`03-候选确认清单`
待确认的新经验、新发现、规则建议。智能体可以自动写入这里。

`04-聊天摘要`
有价值对话或任务的简短摘要。它是历史目录，不是最终规则。

`05-项目资料`
长期项目背景、模板、索引、跨智能体共享资料。

`90-归档废弃`
过期、重复、已吸收、已废弃的内容。优先归档，不要轻易删除。

## 默认查库顺序

1. `01-核心规则`
2. `02-可复用经验库`
3. `03-候选确认清单`
4. `04-聊天摘要`
5. `05-项目资料`

如果任务明确属于某个长期项目，可以把 `05-项目资料` 提前到 `02-可复用经验库` 后面查。
