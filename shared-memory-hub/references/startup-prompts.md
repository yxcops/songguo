# 安装后的启动提示词

用户安装 Skill 后，不会自动创建共享记忆库，也不会自动创建定时任务。

可以复制下面的提示词给 AI 使用。

## 创建共享记忆库

```text
请使用 shared-memory-hub Skill，帮我创建一个 AI智能体共享记忆库。

创建前先问我保存位置。可以保存在 Obsidian 库里，也可以保存在普通本地文件夹里。

不要自动写入未确认的路径。

创建后请运行检查脚本，确认目录完整、入口文件存在、核心规则存在、没有旧目录名残留。

创建完成后，请提醒我是否继续创建自动化任务，但不要直接创建。
```

## 创建 Codex 自动化任务

```text
请使用 shared-memory-hub Skill，根据模板帮我创建两个 Codex 自动化任务：

1. 每日聊天摘要整理
2. 每周候选确认审阅

创建前请先说明：
- 每个任务会读取什么
- 每个任务会写入什么
- 每个任务什么时候运行
- 哪些目录不能自动修改

等我明确确认后再创建。
```

## 创建 Hermes 定时任务

```text
请使用 shared-memory-hub Skill，根据 Hermes 模板帮我创建每日共享记忆库整理任务。

任务只整理 Hermes 自己的有价值会话，不整理 Codex、Claude Code 或其他智能体。

创建前请先确认：
- Hermes 是否能访问共享记忆库路径
- Hermes 是否有读写文件权限
- 任务会写入 04-聊天摘要 和 03-候选确认清单
- 任务不会修改 01-核心规则 和 02-可复用经验库

等我明确确认后再创建。
```

## 接入 Claude Code

```text
请使用 shared-memory-hub Skill，帮我评估如何把 Claude Code 接入这个共享记忆库。

只做诊断和接入方案，不要修改文件。

请告诉我：
- 应该把入口规则放在哪里
- 应该加入什么规则
- Claude Code 能自动做什么
- 哪些动作必须等我确认
```

## 接入 OpenClaw

```text
请使用 shared-memory-hub Skill，帮我评估如何把 OpenClaw 接入这个共享记忆库。

先只做诊断，不要修改配置，不要重启服务，不要写入文件。

请确认：
- OpenClaw 是否能访问共享记忆库路径
- 如果在 Docker、NAS 或远程环境，路径如何映射
- 哪些目录可以读取
- 哪些目录可以写入
- 是否需要额外权限
```
