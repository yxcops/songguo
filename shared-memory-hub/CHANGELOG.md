# Changelog

## v1.2 - 2026-06-22

- 明确 Codex、Hermes、Claude Code、OpenClaw 等平台优先通过 `shared-memory-hub` Skill 使用共享记忆库。
- 补充本地规则与 Skill 的同步原则：本地规则只做短入口或临时适配，发现 Skill 未覆盖场景时必须反向同步 Skill。
- 补充候选升级命名一致规则：文件名、一级标题和 `source_platform` 应保持一致，来源冲突先标记为“来源待确认”。
- 更新 Codex 自动化、Hermes cron、启动提示和平台兼容说明，避免各平台规则分叉。
- 增强检查脚本，提醒旧来源字段口径残留，以及文件名/一级标题与 `source_platform` 不一致的问题。
- 调整检查脚本对 `05-项目资料` 的判断，允许项目资料、项目索引、模板和待办清单等合理类型。

### 已验证

- 本地初始化临时共享记忆库并运行严格检查，结果为无错误、无警告。
- 检查 Python 脚本语法。
- 检查 Skill 和 Agent 配置的 YAML 头部可解析。
- 用真实共享记忆库运行检查，结果为无错误；剩余警告属于历史摘要额外字段或路径类提醒，不是来源字段口径问题。
- 检索确认旧来源字段口径没有残留在共享记忆库规则中。
- 确认 Hermes 本机运行版、Hermes 定时任务提示词、Codex 短入口和 Hermes 短入口都已同步 Skill 优先口径。

### 未处理

- 本轮没有安装到 Codex 本机 Skill 可发现目录。
- Hermes 运行时是否已经加载新版 Skill，仍需刷新或重载后确认。

## v1.1 - 2026-06-22

- 明确 `source_platform` 表示内容原始来源，不表示本次整理者或升级者。
- 补充候选记忆升级规则：从 `03-候选确认清单` 升级到 `02-可复用经验库` 时，正式经验默认继承原候选的 `source_platform` 和 `source_device`。
- 更新 Codex 每周候选审阅提示词，要求列出建议保留的来源字段；来源冲突时标记为“来源待确认”，不直接升级。
- 更新 Hermes 每日整理提示词，要求 Hermes 自己产生的内容写 `Hermes`，整理其他平台资料时保留原始来源。
- 更新初始化脚本生成的默认入口说明和核心规则，让新建共享记忆库也包含来源字段规则。
- 更新检查脚本，增加非标准属性字段、非常见 `source_platform`、目录与 `source_type` 不一致的提醒。

### 已验证

- 本地初始化临时共享记忆库并运行检查脚本。
- 检查 Python 脚本语法。
- 检查 Skill 和 Agent 配置的 YAML 头部可解析。

### 未处理

- 本轮没有推送 GitHub。
- 本轮没有同步 Hermes 本地运行版。
