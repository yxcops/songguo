# 平台接入说明

这个 Skill 的核心是读书模式、笔记格式、阅读画像和推荐书单规则。以下能力不能只靠 Skill 自动生效，需要平台额外接入。

## 安装后第一次使用

用户安装后，先说明三件事：

1. 核心功能可以直接用：读书模式、讨论、整理读书笔记、生成推荐书单。
2. 写入 Obsidian 或本地目录需要用户先确认保存位置。
3. 自动定时、渠道推送、读取日记和历史对话，需要所在平台本身支持。

推荐回复：

```text
每日读书 Skill 已可使用。你可以直接说“开始读书”进入读书模式。

如果你希望我把笔记写进 Obsidian 或本地目录，请告诉我想放在哪个文件夹下面，或者告诉我你已经有的读书笔记目录。
如果你希望每周一早上自动推荐书单，需要再配置你当前平台的定时任务。
```

## 首次设置流程

如果还没有每日读书目录，先问用户目录位置，不要猜测路径，也不要立即创建文件。

用户给出目录后，先展示将创建或复用的结构，等用户确认后再创建。推荐用脚本的 `plan` 命令预览，用 `init` 命令创建。

```bash
python3 scripts/reading_tool.py --parent /path/to/folder plan
python3 scripts/reading_tool.py --parent /path/to/folder init
```

支持三种目录方式：

| 用户意图 | 脚本参数 | 处理方式 |
|---|---|---|
| 放到某个目录下面 | `--parent /path/to/folder` | 创建或复用 `/path/to/folder/每日读书` |
| 这个目录就是每日读书目录 | `--root /path/to/每日读书` | 直接复用这个目录 |
| 已经有读书笔记目录 | `--notes-dir /path/to/读书笔记` | 把它作为书籍笔记目录，不再嵌套新的 `读书笔记` |

如果用户给的目录里已经有 `读书笔记` 加 `每周推荐书单` 或 `每周推荐清单`，把它判断为已有每日读书根目录，直接复用。

## 通用目录

建议使用这个结构：

```text
每日读书/
├── 读书笔记/
├── 每周推荐书单/
├── 阅读画像.md
└── 设置.md
```

如果用户使用 Obsidian，可以放在：

```text
每日读书/
```

这只是推荐位置，不要硬编码。

如果用户已经有 `每周推荐清单` 这个文件夹，不要强行改名成 `每周推荐书单`；直接复用已有名称。

## Codex

Codex 适合做：

- 手动进入读书模式。
- 读取本地目录并整理 Markdown 笔记。
- 根据用户给出的素材生成每周推荐书单。

Codex 是否能自动定时运行，取决于当前客户端是否开放自动化工具。没有自动化工具时，不要承诺会自动推送。

## Claude Code

Claude Code 适合做：

- 在项目或本地目录里维护读书笔记。
- 根据用户给出的文件和上下文整理推荐书单。

如果没有长期会话状态或定时能力，就把“一小时自动退出”和“每周自动推荐”作为使用提醒，而不是承诺已生效。

## Hermes

Hermes 可以做：

- 通过 Skill 进入读书模式。
- 写入 Obsidian 或本地 Markdown。
- 通过 cron 每周触发推荐书单。
- 如果配置了渠道，可以把推荐书单发到指定渠道。

Hermes 安装后不要默认创建定时任务。需要用户明确同意后再配置。

推荐的 Hermes 定时任务语义：

```text
每周一 06:00，使用 daily-reading Skill：
1. 读取最近读书笔记、阅读画像、用户允许读取的日记或历史摘要。
2. 生成本周 5 本推荐书单。
3. 写入“每日读书/每周推荐书单/YYYY-Www 每周推荐书单.md”。
4. 如果用户配置了渠道，再发送提醒。
```

一小时自动退出读书模式可以用 `scripts/reading_tool.py expire --minutes 60` 做状态检查。是否定时执行由 Hermes 配置决定。

## OpenClaw

OpenClaw 可以使用同一套 Skill 规则。是否能自动定时、发送消息、读取历史，取决于 OpenClaw 的具体部署和权限。

接入时先检查：

- 是否能读写用户指定目录。
- 是否有定时任务能力。
- 是否有消息渠道。
- 是否被允许读取日记、历史摘要或其他个人上下文。

## 权限边界

不要默认读取这些内容：

- 日记
- 私聊记录
- Codex 历史
- Claude Code 历史
- 微信读书书架
- NAS 文件

只有用户明确授权，且当前平台确实能访问时，才使用这些资料。
